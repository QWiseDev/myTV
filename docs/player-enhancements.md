# 播放器增强

## 功能入口

- 播放器设置中的“视频超分”可选关闭、1.5x、2x、3x、4x；“超分模式”可选 Anime4K Mode A/B/C。倍率和模式保存在当前浏览器，新播放器默认关闭超分。
- 播放器下方“弹幕管理”支持搜索影片、选择弹幕剧集、恢复自动匹配、屏蔽词和顶部/底部/彩色过滤。手动匹配按影片、年份、豆瓣 ID 和播放集数隔离，最多保留 100 条选择。
- 豆瓣短评支持站内加载更多、失败重试和空状态。翻页使用豆瓣页面的下一页游标，切换影片会隔离旧请求。

## 运行条件

- 超分由浏览器 GPU 执行，需要 HTTPS（本机 localhost 除外）及可用的 WebGPU 适配器。视频源仍须允许跨域读取；不支持时或发生 GPU 错误会回退原画。
- 超分输出限制为 16,777,216 像素且不能超过设备纹理尺寸限制。高分辨率视频选择高倍率可能被拒绝；遇到显存不足应降低倍率。原生画中画、AirPlay、投屏使用原视频，不包含浏览器画布超分。
- 弹幕搜索和手动选集复用管理面板中的“弹幕 API 地址”，要求兼容 `huangxd-/danmu_api` 的 `/api/v2/search/anime`、`/api/v2/bangumi/{id}` 和 `/api/v2/comment/{id}`。未配置会提示配置，原有自动弹幕备用源不受影响。
- 新增 `/api/danmaku?action=search|episodes|comment` 查询路由，沿用项目登录中间件，只允许固定上游路径，不接受客户端传入代理目标。
- 短评仅获取豆瓣公开页面，受上游可达性、限流和验证限制，不保证所有影片都有评论。不需要新增数据库或部署独立评论服务。
